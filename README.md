# Fundamentos de programación en Dart

Proyecto académico con 15 ejercicios de lógica y programación orientada a objetos.

## Conceptos aplicados

- Variables y tipos de datos
- Condicionales
- Bucles
- Funciones
- Listas
- Clases y objetos
- Encapsulamiento
- Herencia mediante la interfaz `Ejercicio`
- Polimorfismo en el menú principal
- Validación de entradas

## Ejecución

1. Instala Dart SDK 3 o superior.
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta:

```bash
dart run bin/main.dart
```

5. Día laboral

7. Residuo de una división
8. Suma de números pares
9. Diferencia de fracciones
10. Longitud de una palabra
11. Promedio de cuatro números
12. Menor de cinco números
13. Contador de vocales
14. Factorial
